# Zilin Chen — Personal Homepage

This repository contains Zilin Chen's personal homepage and research notes.

The site presents work across robotics, control, simulation, embedded systems,
and programmable matter, along with a concise profile and downloadable CV.

## Content

- `content/` — profile, skills, and research/project articles
- `static/uploads/` — downloadable materials such as the CV
- `assets/` — site-wide visual customizations

The site is published automatically from the main branch.
